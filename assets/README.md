# assets/

- `demo.mp4` is the video the application starts with. **It is a placeholder (a synthetic scene) so that the project runs
  out of the box: replace it with a real video, keeping the exact file name `demo.mp4`.** If the file is absent, the
  application starts with the webcam instead. Use a short clip (10-30 s, 640x480 or smaller, a few MB).
- `models/` holds the optional deep-learning models (see `models/README.md`).
